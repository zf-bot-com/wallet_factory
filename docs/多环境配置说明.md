# 多环境配置说明

## 概述

本项目支持多环境配置，可以在编译时指定使用不同的配置文件。配置文件使用 `go:embed` 嵌入到二进制文件中，因此不同环境的二进制文件是完全独立的。

## 配置文件

项目中包含以下配置文件：

- `config.env.dev` - 开发环境配置
- `config.env.prod` - 生产环境配置
- `config.env.example` - 配置文件示例

## 使用方法

### 1. 本地编译

使用 `make` 命令编译时，通过 `ENV` 参数指定环境：

```bash
# 编译开发环境版本（默认）
make linux

# 编译生产环境版本
make linux ENV=prod

# 编译 Windows 版本（生产环境）
make win ENV=prod

# 编译 macOS 版本（开发环境）
make mac ENV=dev
```

### 2. 部署到服务器

使用 `deploy.sh` 脚本部署时，第一个参数指定环境：

```bash
# 部署生产环境到默认服务器（gpu）
./deploy.sh prod

# 部署开发环境到指定服务器
./deploy.sh dev gpu /srv

# 完整参数格式
./deploy.sh [环境] [服务器地址] [服务器路径]
```

参数说明：
- 第1个参数：环境名称（dev/prod），默认为 prod
- 第2个参数：服务器地址，默认为 gpu
- 第3个参数：服务器路径，默认为 /srv

### 3. 验证配置

编译时会显示使用的环境：

```bash
$ make linux ENV=prod
准备配置文件: config.env.prod -> config.env
✅ 配置文件已准备: prod 环境
编译 Linux 版本 (环境: prod)...
✅ 编译完成: factory-linux (prod)
```

## 工作原理

1. **准备阶段**：`make` 命令首先执行 `prepare-config` 目标，将 `config.env.$(ENV)` 复制为 `config.env`
2. **编译阶段**：Go 编译器通过 `//go:embed config.env` 将配置文件嵌入到二进制文件中
3. **运行阶段**：程序启动时从嵌入的配置中读取环境变量

## 添加新环境

如果需要添加新的环境（如测试环境），只需：

1. 创建新的配置文件：`config.env.test`
2. 编译时指定环境：`make linux ENV=test`

## 注意事项

1. **配置文件安全**：生产环境的配置文件包含敏感信息（如 Redis 密码），请勿提交到版本控制系统
2. **环境隔离**：不同环境的二进制文件是完全独立的，配置在编译时就已确定
3. **默认环境**：如果不指定 `ENV` 参数，默认使用 `dev` 环境
4. **配置验证**：如果指定的配置文件不存在，编译会失败并提示可用的配置文件

## 配置项说明

### Redis 配置

- `REDIS_ADDR` - Redis 服务器地址和端口
- `REDIS_PASSWORD` - Redis 密码（可选）
- `REDIS_DB` - Redis 数据库编号
- `REDIS_POOL_SIZE` - 连接池大小
- `REDIS_MIN_IDLE_CONNS` - 最小空闲连接数
- `REDIS_DIAL_TIMEOUT` - 连接超时时间
- `REDIS_READ_TIMEOUT` - 读取超时时间
- `REDIS_WRITE_TIMEOUT` - 写入超时时间

### 其他配置

- `POST_URL` - 结果上传地址（可选）
