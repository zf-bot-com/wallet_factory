## 场景 2：添加新的 Worker 节点

### 1. 编辑配置文件

```bash
vim servers.env.prod
```

添加新服务器：

```bash
# 生产环境服务器列表
gpu:/srv
worker-01:/srv
worker-02:/srv
worker-03:/srv  # 新添加
worker-04:/srv  # 新添加
```

### 2. 重新部署

```bash
./deploy.sh prod
```

脚本会自动部署到所有 5 个服务器（包括新添加的）。

## 场景 3：部署到不同路径的服务器

### 1. 配置不同路径

```bash
# 生产环境服务器列表
gpu:/srv
worker-01:/home/ubuntu/trap-factory
worker-02:/opt/applications/trap-factory
```

### 2. 执行部署

```bash
./deploy.sh prod
```

脚本会自动将程序部署到各自指定的路径。

## 场景 4：处理部署失败

### 1. 模拟失败场景

添加一个不存在的服务器：

```bash
# 生产环境服务器列表
gpu:/srv
worker-01:/srv
invalid-server:/srv  # 不存在的服务器
worker-02:/srv
```

### 2. 执行部署

```bash
./deploy.sh prod
```

### 3. 预期输出

```bash
==========================================
[步骤 3/4] 批量上传到服务器
==========================================
[INFO] [1/4] 上传到 gpu:/srv...
[SUCCESS] 上传成功: gpu

[SUCCESS] 上传成功: worker-01
```

## 场景 5：批量管理服务

部署完成后，可以使用以下脚本批量管理服务：

### 批量查看服务状态

```bash
#!/bin/bash
# check-status.sh

SERVERS="gpu worker-01 worker-02"

for server in $SERVERS; do
    echo "=========================================="
    echo "服务器: $server"
    echo "=========================================="
    ssh $server 'sudo supervisorctl status trap-factory'
    echo ""
done
```

### 批量重启服务

```bash
#!/bin/bash
# restart-all.sh

SERVERS="gpu worker-01 worker-02"

for server in $SERVERS; do
    echo "重启 $server..."
    ssh $server 'sudo supervisorctl restart trap-factory'
done

echo ""
echo "所有服务已重启，等待 5 秒后检查状态..."
sleep 5

for server in $SERVERS; do
    echo "=========================================="
    echo "服务器: $server"
    echo "=========================================="
    ssh $server 'sudo supervisorctl status trap-factory'
    echo ""
done
```

### 批量查看日志

```bash
#!/bin/bash
# view-logs.sh

SERVERS="gpu worker-01 worker-02"

for server in $SERVERS; do
    echo "=========================================="
    echo "服务器: $server - 最近 20 行日志"
    echo "=========================================="
    ssh $server 'sudo supervisorctl tail trap-factory' | tail -20
    echo ""
done
```

## 最佳实践

1. **部署前检查**
   ```bash
   # 检查配置文件
   cat servers.env.prod

   # 检查 SSH 连接
   for server in gpu worker-01 worker-02; do
       echo "测试 $server..."
       ssh $server 'echo OK'
   done
   ```

2. **部署后验证**
   ```bash
   # 批量检查服务状态
   for server in gpu worker-01 worker-02; do
       echo "=== $server ==="
       ssh $server 'sudo supervisorctl status trap-factory'
   done
   ```

3. **定期清理备份**
   ```bash
   # 批量清理旧备份（保留最近 3 个）
   for server in gpu worker-01 worker-02; do
       echo "清理 $server 的旧备份..."
       ssh $server 'cd /srv && ls -t trap-factory.backup.* | tail -n +4 | xargs rm -rf'
   done
   ```

4. **监控部署日志**
   ```bash
   # 实时查看某个服务器的日志
   ssh worker-01 'sudo supervisorctl tail -f trap-factory'
   ```
